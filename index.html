Forja

A code-review LLM for Portuguese, from training to production

A small model (Qwen2.5-Coder 0.5B) trained, evaluated and served for one real task: reviewing pull requests in Portuguese. Mined real bug fixes, post-trained with LoRA, measured everything with one yardstick, served it behind an OpenAI-compatible API and wired it into a GitHub App.

REAL BUGS FOUND (OF 199)9 → 27
COMMENT PRECISION3% → 23%
FORGETTING ON GENERAL EVALNONE
SERVING THROUGHPUT (BATCHING)2.6×

Data was the lever, not the method: synthetic training perfected the format but not the bugs. Switching to real fixes moved recall and precision together.
